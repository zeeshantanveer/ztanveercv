How I build

Front ends that work for everyone

The parts of web development that users feel but rarely see, done by default rather than as an afterthought.

  • 01

    Standards and responsive

    Semantic HTML5, CSS3/SCSS and modern JavaScript (ES6+), with responsive layouts that hold up from small phones to wide screens.

  • 02

    Accessible

    WCAG practices: real buttons and labels, keyboard navigation, visible focus, readable contrast and meaningful alt text.

  • 03

    Search friendly

    On-page SEO with a clear heading hierarchy, descriptive titles and meta tags, and structured data where it helps.

  • 04

    Fast JavaScript

    Deferred and trimmed scripts, small bundles, lazy loading and no layout shift, checked with Lighthouse and Core Web Vitals.

  • 05

    Browser QA

    Tested across major browsers and devices before release, with automated tests (Jest, PHPUnit, Playwright) where they pay off.

  • 06

    Design to code

    I work from Figma and Sketch files and turn them into reusable components that match the design and stay consistent.

This page follows the same rules. It is hand-written semantic HTML and CSS with no framework, a skip link, keyboard-friendly navigation, reduced-motion support, Person structured data for search engines, and a light or dark theme that is saved in local storage.
